# TierTagger

A modern Minecraft Fabric mod that displays player PvP rankings from [Navy Tiers](https://navytiers.com) directly in their nametags and player lists.

## Features

- **Navy Tiers Integration**: Support for Crystal, Netherite, and Sword rankings.
- **Multi-Mode Display**:
  - **Selected**: Shows the rank for your chosen gamemode.
  - **Highest (Auto)**: Automatically displays the player's best rank across all modes.
  - **All**: Shows all active rankings in a concise format (e.g., `[C: LT1 | S: HT2]`).
- **Visual Icons**: Custom mode icons rendered next to tiers for better visibility.
- **Easy Search**: In-game command and UI to search for any player's rankings.
- **Lightweight & Fast**: Built with performance in mind using efficient caching.

## Usage

- Open the configuration menu using **Ukulib** integration.
- Use `/tiertagger <player>` to query rankings in-game.
- Cycle through display modes using the configured keybind.
